## Evolution ## 

Elasticsearch is an open-source, distributed search and analytical engine. It's designed to handle real-time search and analytics with ease. 
`Logstash` is a server-side data processing pipeline that ingest data from multiple sources, transforms it and sends it to your preferred stash for storage. It allows users to pre-process and structure the data to make it more analyzable and searchable.

`Kibana` is an open source data visualization dashboard for elasticseatch. It allows creation and sharing of dynamic dashboards easily.

`Elastic Cloud` offers a hosted and fully managed elasticsearch service, making it easier to deploy, manage and scale their elasticsearch clusters without worrying about elasticsearch clusters.
